# Copilot compatibility instructions

The authoritative shared guidance is [`docs/agents/project-guidance.md`](docs/agents/project-guidance.md), and current architecture is documented in [`docs/architecture/overview.md`](docs/architecture/overview.md).

Preserve .NET 10, the existing microservice boundaries, and .NET Aspire. Do not introduce Docker Compose as an Aspire replacement. Use MassTransit through `ServiceDefaults`, with RabbitMQ for Development and Azure Service Bus for production/non-development. Keep broker-specific configuration out of application consumers and services. Treat production infrastructure, Application Insights export, dependency readiness, and delivery guarantees as planned until the repository implements and validates them.
